# MotionEye NVR

Нативный клиент (C++/Qt6) для Debian 13 / Linux x86_64:

* мозаика всех камер motionEye (2, 3 и больше — сетка подбирается под размер окна);
* кнопка **«Записи»** на каждой камере → окно со списком записей по дням и плеером
  (пред./след., перемотка, скорость 0.5×–8×, автопереход, полный экран);
* несколько серверов motionEye одновременно: локальный (`http://localhost:8765`) и удалённые;
* автозапуск при входе в графический сеанс (`/etc/xdg/autostart`);
* работает с motionEye ≥ 0.44 (сессия `/login`) и со старыми 0.42/0.43 (подпись `_signature`);
* если сервер ещё не поднялся (docker стартует позже) — переподключается сам.

## Установка на сервере

```bash
sudo apt install ./motioneye-nvr_1.0.0_amd64.deb
```

Подтянутся зависимости (Qt6, Qt Multimedia/FFmpeg). Автозапуск включается сам, но он срабатывает
**при входе пользователя в графический сеанс**: на машине-«мониторе» включите автологин
(в настройках GDM/LightDM/SDDM). Запуск вручную: `motioneye-nvr`
(`--fullscreen` / `--windowed`).

Без пакета: скопировать `dist/motioneye-nvr` в `~/.local/bin`, поставить
`libqt6multimedia6 libqt6widgets6 qt6-qpa-plugins`, а `packaging/motioneye-nvr-autostart.desktop`
положить в `~/.config/autostart/`.

## Использование

* Первый запуск создаёт сервер «Локальный» → `http://localhost:8765`, пользователь `admin`,
  пустой пароль. Логин/пароль меняются в **Настройки** (ПКМ по окну или кнопка в панели);
  там же добавляются удалённые серверы (`http://host:port`) и кнопка «Проверить подключение».
* Двойной клик по камере — развернуть на всё окно, `Esc` — назад. `F11` — полный экран
  (панель скрывается), `Ctrl+Q` — выход.
* Записи: день → запись. Клип скачивается во временный файл (`~/.cache/motioneye-nvr`,
  хранится только текущий и удаляется при смене/закрытии) и воспроизводится.
  Пробел — пауза, ←/→ — ±5 с.
* Конфиг: `~/.config/motioneye-nvr/config.json` (права 0600, пароли хранятся открытым текстом).

## Как устроено (память)

Кадры тянутся по одному запросу за раз (`/picture/<id>/current/`), только пока плитка видна
(свернули окно — опрос прекращается). Один `QImage` на камеру перезаписывается новым кадром,
ответы сети освобождаются сразу, видео-клипы не накапливаются. Проверено AddressSanitizer/LeakSanitizer
(утечек в коде приложения нет) и замером RSS на 25 кадр/с с циклами открытия/закрытия плеера.

## Сборка

Нужна среда Debian 13 (так бинарник совпадёт по библиотекам с целевой системой):

```bash
sudo apt install g++ cmake qt6-base-dev qt6-multimedia-dev dpkg-dev
./build.sh && packaging/make-deb.sh
```

Исходники: `src/` (`MotionEyeClient` — авторизация и запросы, `CameraTile` — живая картинка,
`MosaicWidget` — раскладка, `RecordingsDialog` — записи и плеер, `SettingsDialog`, `MainWindow`).
